Glosario de Desarrollo Web

Algoritmo: Es una secuencia lógica y finita de pasos que permite solucionar un problema o cumplir un objetivo específico.

Navegador: Es el software o aplicación que permite el acceso a la Web, interpretando el código HTML para que el usuario pueda visualizar la información.

Servidor: Es una computadora de gran potencia encargada de "servir" o enviar datos a otros dispositivos conocidos como clientes dentro de una red.
